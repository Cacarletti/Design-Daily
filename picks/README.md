# Picks

Pasta dos seus **picks do dia** — a seleção resumida e compartilhável.

Cada arquivo é um dia: `AAAA-MM-DD.json` (ex: `2026-06-01.json`).

## Como adicionar picks

1. Na aba **Notícias** do site, clique na ⭐ dos cards que você curtir.
2. Clique em **"Exportar picks do dia ↓"** — baixa um arquivo `AAAA-MM-DD.json`.
3. Coloque o arquivo aqui nesta pasta `picks/`.
4. Dê `git add picks && git commit -m "picks do dia" && git push`.

A página **⭐ Picks** do site mostra automaticamente todos esses arquivos,
do dia mais recente ao mais antigo. É o link que você compartilha com outras pessoas.
